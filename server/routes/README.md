# Matrimony App

A matrimony web application built as a portfolio project.

## Features

- Register and login with JWT authentication
- Create and edit a matrimony profile
- Search profiles by gender, age, city, education and religion
- Admin approval for new profiles
- Send, accept and reject interests

## Tech Stack

- Node.js, Express
- MongoDB Atlas, Mongoose
- JWT, bcryptjs
- React (frontend, in progress)

## Setup

1. Go to the server folder and run `npm install`
2. Create a `.env` file with PORT, MONGO_URI and JWT_SECRET
3. Run `npm run dev`
